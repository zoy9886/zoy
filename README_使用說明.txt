豐譽工地 RPG 原創模組化素材庫 V1

共 268 個獨立透明 PNG（64×64 像素），另含每分類 Sprite Sheet、素材總覽與 JSON/CSV 索引。

檔案分類：
01_ground 混凝土地板
02_floor_details 地面標示
03_structure 牆、柱、梁
04_rebar_formwork 鋼筋與模板
05_scaffolding 施工架
06_safety 安全防護
07_materials 材料與堆置
08_equipment 機具與工具
09_planning_quality 圖面、電腦與品管
10_characters 工地角色

使用方式：先以 ground 拼地板，再依 manifest.json 的 layer 分層放置；collision=true 的素材需要依遊戲地圖設定阻擋區。
注意：此為第一批程式化像素素材，非逐幀手繪成品。部分 variant 是同一類素材的材質、色彩或細節變化；不代表 268 種完全不同物件。角色目前是靜態造型，不包含四方向走路動畫。正式製作應再依參考場景統一比例與遮擋、碰撞。
