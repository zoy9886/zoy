豐譽工地 RPG｜原創素材＋可執行程式碼整合包

開始方式：解壓縮整個 ZIP（不要只開啟 ZIP 內的 HTML），雙擊 index.html。
不需要安裝程式，也不需要網路。可用 Chrome / Edge 開啟。

操作：方向鍵/WASD 移動；E/空白鍵或右下角按鈕互動；下方按鈕切換四個組別。
玩法：先找學長姐對話 → 調查三個物件 → 回去回答問題 → 完成組別。

包含：
- index.html：遊戲入口
- js/game.js：實際地圖拼接、角色繪製、碰撞、互動、對話、任務、進度儲存
- assets/：268 張 64×64 PNG，10 類素材、sprite sheet、manifest、總覽
- data/asset-index.json：依類別與名稱整理的程式索引

說明：此為獨立的「素材整合可玩測試版」，不是原本 GitHub 全功能遊戲的原始碼，也沒有覆蓋 GitHub。這版用實際 PNG 圖檔組成地圖，不是整張背景圖片。地圖配置、任務與碰撞仍是初版，人物只有有限的幀變化，尚未達到完整精緻商業 RPG 美術品質。請保留資料夾相對路徑。
